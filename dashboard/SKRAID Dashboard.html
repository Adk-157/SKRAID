R_skid Computation

edge-side per 2-second window
R_skid_base = 0.5 · V_vision + 0.3 · σ²(a_z) + 0.2 · (Δroll + Δyaw)
R_skid_final = R_skid_base · (1 + 0.3 · v_norm) // v_norm = clip(v_kmh / 60, 0, 1)
R_skid_displayed = min(1.0, R_skid_final · W_modifier) // applied in cloud
Safe
R < 0.33
Caution
0.33 ≤ R < 0.66
High Risk
R ≥ 0.66
V_vision — model-derived surface hazard score [0, 1]
σ²(a_z) — variance of vertical acceleration over window
Δroll, Δyaw — IMU angular deltas (rad)
v_norm — normalised speed factor
W_modifier — OpenWeatherMap-derived multiplier
edge → cloud — JSON upload after each session
